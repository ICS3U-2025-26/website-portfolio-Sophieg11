Unit 1 - Introduction to Computer Science

Introduction to Programming

In this introduction to coding we used Scratch to draw basic shapes using changes in movement, time and angles. To add simplicity to my code, I used repeat blocks for repetitive actions. This taught some of the basic actions available when coding.

PC Build

Using our learning of the parts of a PC and their uses, we created our own PC based on listed requirements. This taught me about the physical system behind my electronics and the ways in which each part interacts.

PB & J Pseudocode

In this project we learned about pseudocode and the importance of intentional word choice. The task at hand was incredibly simple, you needed to instruct someone to make a peanut butter and jelly sandwich, but, you had to ensure that you were incredibly detailed to avoid any possible erros in the process. This taught me one way to prep my code and outline my tasks.

Implementing Algorithms

In this algorithms practice I learned to implement mathematical values into my code to get a desired result. This taught me a more logic/mathematically based side of coding.
